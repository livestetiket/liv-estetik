Liv Estetik cPanel upload guide

Upload these two ZIP files from the project root:

1. liv-estetik-public-liv.zip -> the main website document root (usually public_html).
2. liv-estetik-admin-liv.zip -> the admin subdomain document root.

Extract each ZIP directly into its matching document root. Each ZIP contains the built site's index.html and assets at the archive root. Do not extract both into the same folder because both contain an index.html.

These ZIPs contain only the built public site and staff dashboard. The API and booking database remain on the configured backend host; do not upload the backend .env file or database credentials to a public web folder. Booking, staff login, reports, and dashboard data require the backend API and database to be online, with the latest backend code deployed.

The latest public build includes the JPEGs currently in the project. For future image replacements, add the JPEGs under liv_estetik-frontend/public/images/, rebuild the public site, and create a new ZIP.
